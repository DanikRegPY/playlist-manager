CLI Playlist Manager / Konsolen-Playlist-Manager

## 🇬🇧 English

A simple command-line interface (CLI) application written in Python to manage a music playlist. 

### Features
* **Add songs:** Append new tracks to your playlist.
* **View playlist:** Display all saved tracks with automatic numbering.
* **Remove songs:** Delete tracks by selecting their index number.
* **Input validation:** Handles invalid inputs and out-of-range numbers safely without crashing.

### How to Run
1. Make sure you have Python 3 installed.
2. Run the script in your terminal:
   ```bash
   python playlist.py
   ```


## 🇩🇪 Deutsch

Eine einfache Konsolenanwendung (CLI) in Python zur Verwaltung einer Musik-Playlist.

### Funktionen
* **Songs hinzufügen:** Neue Titel zur Playlist hinzufügen.
* **Playlist anzeigen:** Alle gespeicherten Titel mit automatischer Nummerierung auflisten.
* **Songs löschen:** Titel gezielt über ihre Listennummer entfernen.
* **Fehlerbehandlung:** Sichere Überprüfung der Benutzereingaben (fängt falsche Zahlen oder Buchstaben ab).

### Ausführung
1. Stellen Sie sicher, dass Python 3 installiert ist.
2. Starten Sie das Skript im Terminal:
   ```bash
   python playlist.py
   ```
